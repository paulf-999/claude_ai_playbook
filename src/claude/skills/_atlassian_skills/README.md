# 🔗 Atlassian Skills

Jira and Confluence workflow skills. Require the Atlassian MCP server (`make enable_mcp server=Atlassian`, then restart Claude Code).

| Skill | Description | Version | Tested |
|---|---|---|---|
| `/confluence-create-page` | Interactively create a Confluence page for a known team pattern | 1.6.0 | [yes](confluence-create-page/tests/evals.yaml) |
| `/jira-create` | Create an individual Jira ticket with full field configuration and story point validation | 0.4.0 | [yes](jira-create/tests/evals.yaml) |
