## Scoring guides

**Theme scores (1–10):**

| Score | Meaning |
|:---|:---|
| 9–10 | Excellent — sets the bar |
| 7–8 | Good — meets the bar with minor gaps |
| 5–6 | Acceptable — works but has notable gaps |
| 1–4 | Needs work — significant issues |

**Overall score:** average of the five theme scores, rounded to one decimal place.

**Grade mapping:**

| Score | Grade |
|:---|:---|
| 9.5–10 | A+ |
| 9.0–9.4 | A |
| 8.5–8.9 | A− |
| 8.0–8.4 | B+ |
| 7.5–7.9 | B |
| 7.0–7.4 | B− |
| 6.5–6.9 | C+ |
| 6.0–6.4 | C |
| 5.5–5.9 | C− |
| 5.0–5.4 | D+ |
| 4.0–4.9 | D |
| < 4.0 | F |

**Verdict determination — based solely on Must items:**

| Verdict | `<verdict>` | `<verdict_emoji>` | Condition |
|:---|:---|:---|:---|
| Approve | `Approve` | ✅ | No Must items AND no Should items |
| Approve with suggestions | `Approve with suggestions` | 💬 | No Must items, but Should items present |
| Needs revision | `Needs revision` | ❌ | Any Must item present |

The overall score does not determine the verdict — Must items do.

## Theme guidance (pass to the agent)

**🏗️ Structure** — Does the page use headings, bullets, and tables effectively? Is it
scannable in under 30 seconds? Penalise walls of prose, inconsistent heading hierarchy,
and missing visual structure.

**✅ Completeness** — Are the sections a reader would expect for this type of page present?
Score based on what is visible — if the page type/pattern is unclear, apply generic
completeness criteria (introduction, body, outcomes/next steps).

**💬 Clarity** — Is the language appropriate for the intended audience? Are terms explained
where needed? Penalise unexplained jargon, ambiguous statements, and passive constructions
that obscure ownership.

**📐 Consistency** — Does the page match DM team formatting conventions? Consistent use of
em-dash separators in titles, bullet style, panel usage, and section ordering all matter.
Penalise formatting that deviates from established patterns on similar pages.

**🔗 Links & references** — Are internal links present where expected (referenced Jira
tickets, related pages)? Do external links have meaningful anchor text? Penalise broken
or missing links where links are clearly expected.

## Header bullet guidance (pass to the agent)

- Write 1–3 bullets in plain English for a mixed technical/non-technical audience
- Do not repeat scorecard detail — convey the overall signal only
- **For Needs revision:** cover only the Must items — what must change before this is ready
- **For Approve with suggestions:** lead with why the page is sound, then note what the Should items address
- **For Approve:** explain briefly why the page is ready (clear, complete, no concerns)

---

## Notes field guidance (pass to the agent)

- 1–2 bullets per cell using `•` as the bullet character and `<br>` between bullets
- Each bullet: bold keyword + colon + brief plain-English point (e.g. `• **Scannability**: Headers and bullets used consistently throughout`)
- Plain English — assume a mixed technical and non-technical audience
- High-level observations only — avoid quoting specific lines from the page
