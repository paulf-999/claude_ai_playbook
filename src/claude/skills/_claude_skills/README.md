# 🤖 Claude Skills

Meta-skills for managing the Claude setup and improving Claude's own output and decision-making.

| Skill | Description | Version | Tested |
|---|---|---|---|
| `/claude_capture_session_prompts` | Capture session prompts from history.jsonl into a structured markdown table for review and planning | 0.1.0 | no |
| `/claude_kaizen` | Self-improving loop—audit recent corrections for recurring patterns, promote verified ones into rules with proof (evals), prune stale rules | 0.1.0 | no |
| `/claude_review_config` | Audit your global Claude config across six quality dimensions. Receive scorecard with A–F grade, gap analysis, and actionable recommendations | 0.1.0 | no |
| `/claude_setup_graphify` | Set up Graphify on a repo to generate a local AST-based knowledge graph, reducing token cost for codebase exploration | 0.1.0 | no |
