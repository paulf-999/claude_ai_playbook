# 🛠️ Git Skills

Git workflow automation for feature/hotfix PR creation and repository management.

| Skill | Description | Version | Tested |
|---|---|---|---|
| `/git-create-pr` | Create GitHub PR from staged changes, branch, commit message, and PR body | 2.1.0 | yes |
| `/git-review-pr` | Review a GitHub PR with the `code-reviewer` agent and post a scored review comment once approved | 2.0.0 | yes |
