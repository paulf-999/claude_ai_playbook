# 🛠️ Git Skills

Git workflow automation for feature/hotfix PR creation and repository management.

| Skill | Description | Version | Tested |
|---|---|---|---|
| `/git_create_pr` | Create GitHub PR from staged changes, branch, commit message, and PR body | 1.2.0 | yes |
| `/git_review_pr` | Review a GitHub PR with the `code_reviewer` agent and post a scored review comment once approved | 0.5.0 | no |
