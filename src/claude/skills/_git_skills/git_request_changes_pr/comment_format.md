# 💬 Inline comment format

Each inline comment uses this structure:

````
[_Generated by Claude_]
[blank line if attribution line is present]
* <issue 1>
* <issue 2>

**Suggested fix:**
```lang
<fix>
```
````

## Rules

- `_Generated by Claude_` — prepend only if user opted in during Phase 3
- `**Suggested fix:**` block — omit entirely if no concrete code fix applies
- Bullets use `*`, not `-`
- One issue per bullet — concise, one sentence
- Code in `**Suggested fix:**` must be runnable — no pseudocode
- Use the appropriate language tag (`bash`, `python`, `sql`, `yaml`) on the code fence
