# 📅 Meetings Skills

Skills for anything meeting-related — scheduling a new meeting, preparing for a recurring 1-to-1, or planning a sprint ceremony.

| Skill | What it does | Version | Tested |
|---|---|---|---|
| `/weekly_one_to_one_prep` | Prepare for a 1-to-1 or weekly manager catch-up — gather topics, identify the core message, filter async items, prioritise, time-box, and produce a final agenda | 1.1.0 | no |
| `/sprint_planning_dpe_team` | Review capacity, identify committed tickets, confirm scope, and optionally update the sprint goals page | 0.1.0 | yes |
| `/schedule_meeting` | Schedule a meeting — check calendar availability, propose a timeslot, draft the meeting invite body, and optionally draft a Teams follow-up message | 1.0.0 | no |
