# Catch-up Agenda Template

Format reference and output log for the `/weekly_one_to_one_prep` skill.

---

## Agenda format

```
# [Meeting title] — [Date]

**Core message:** [One sentence — the thing the manager walks away thinking]

1. [Item title]
   - **Keyword:** text
   - **Keyword:** text

2. [Item title]
   - **Keyword:** text

...

N. Manager's items (2 mins)
```

**Format rules:**
- Number each item. No timings in headings.
- Every bullet uses a bold keyword prefix: `- **Keyword:** text`
- Sub-bullets follow the same pattern. Flat bullets: max 3 per item.
- Blocker heading format: `[TICKET-REF](link) — topic description`. Status belongs in a `- **Status:**` bullet.
- Always reserve the last 2 mins for manager's items.
